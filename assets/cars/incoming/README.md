# Drop sports-car models here

Save free **CC Attribution (CC-BY)** or **CC0** car models from Sketchfab here as `.glb` (Sketchfab's "Download 3D
Model" → glTF Binary). Downloading needs a Sketchfab account, so this step is done by hand.

Good candidates (all marked CC Attribution and downloadable at the time of writing; check each page's licence before
saving):

- *Lamborghini Aventador SVJ SDC (FREE)* by Lambo_SC04
- *Lamborghini Huracan Twin Turbo [LOST]* by BlackSnow02
- *Lamborghini Gallardo lp560* by BlackSnow02
- *Lamborghini Aventador* by blackcube4
- *Koenigsegg One Pro* by Alister.Dsa
- a Ferrari-style coupe (search Sketchfab for "ferrari" with the Downloadable + CC licence filters)

For each file, add a line to `CREDITS.md` in this folder with: the model's title, author, Sketchfab URL and licence.
The game then cuts each model down to a game-sized mesh, fits Kenney-style wheels to its axles, and gives it a
parody badge (the way the plaza shops are parodied), so no real maker's name or logo is shown.
